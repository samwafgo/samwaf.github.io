安全运营报告

2026/11/13大约 10 分钟

功能简介

安全运营报告按自然日、自然周、自然月汇总当前实例全部网站的安全运营情况，提供请求与阻止统计、趋势、TOP 榜单、操作审计汇总和网站、证书快照。报告生成后保存在本机，可预览、下载为单文件 HTML，离线查看或通过浏览器打印为 PDF。

入口：系统设置 → 安全运营报告，仅超级管理员可管理。Vue2 与 Vue3 管理端的操作一致。

版本要求

前端入口已随 Vue2 / Vue3 v1.3.335 提供。报告后端尚未包含在 v1.3.25-beta.10 及之前的已发布版本中，需要配套支持报告功能的后端。仅升级前端不会增加后端报告能力。

默认设置与生成周期

自动报告总开关及日报、周报、月报开关默认开启。报告默认仅在本机生成，不自动创建通知订阅。

类型默认生成时间统计周期
日报每日 00:30前一自然日
周报每周一 08:00上一自然周，周一至周日
月报每月 1 日 09:00上一自然月

生成计划和日期范围都使用服务器本地时区，页面会显示服务器时区。任务列表中的统计周期为最终范围；浏览器所在时区不决定报告周期。后台按分钟检查到期计划，生成任务需要排队执行。

  • 首次启用从当前周期开始，不自动回补此前已经结束的周期。例如周三首次启用日报，会在周四到达生成时间后生成周三的日报。
  • 总开关关闭后再开启，会重新确定自动生成起点。
  • 停机后恢复时只检查最近一个已结束且符合条件的周期，不逐期补齐停机期间的所有报告；更早周期可手动生成。
  • 关闭总开关只停止自动生成，仍可保存配置、手动生成、查看和下载已有报告。

操作步骤

1. 配置报告

进入 报告设置，按需调整以下内容，点击 保存配置。

配置项默认值可设置范围或说明
启用自动报告开启控制自动生成
日报 / 周报 / 月报均开启可分别关闭不需要的周期
生成时间日 00:30、周一 08:00、每月 1 日 09:00HH:mm，按服务器时区执行
站点范围全实例汇总汇总当前实例全部网站，不提供单网站筛选
报告语言中文中文 / English；决定生成的 HTML 内容语言
TOP 榜单条数105–50 的整数
保留天数30 天1–365 的整数
产物配额500 MB10–10240 的整数

报告语言与管理端界面语言分别设置。切换界面语言或修改报告设置，不会改变已经生成的 HTML。

2. 手动生成日报、周报或月报

  1. 切换到 报告任务，点击 手动生成。
  2. 选择报告类型，系统默认选中上一周期；也可点击 上一周期 重新选择。
  3. 在 周期内日期 中选择一天。日报取该日，周报取该日所在的周，月报取该日所在的月。
  4. 核对弹窗显示的 所选周期，点击 手动生成。
  5. 任务受理后会进入列表，等待状态更新。

只能选择已经结束的自然周期。例如 11 月 13 日可以生成 11 月 12 日的日报，也可以选择 10 月任意一天生成 10 月月报，不能生成尚未结束的 11 月月报。

同一类型、同一周期重复提交时，已有排队中、生成中、已完成或部分完成的任务会直接复用。失败、过期或已删除的周期可手动重新排队。手动生成只保存本地报告，不触发周期摘要通知。

3. 查看任务与状态

列表显示报告类型、报告编号、统计周期、状态、创建 / 完成时间、文件大小和生成方式。页面打开期间每 5 秒刷新一次，也可点击 刷新；离开页面后停止轮询。

状态说明可进行的主要操作
排队中等待生成等待或刷新
生成中正在采集与生成报告等待或刷新
已完成已生成可读取的报告预览、下载、删除
部分完成部分数据缺失或不可用，报告内已标注预览、下载、删除，并查看缺失说明
失败未能生成可下载产物查看任务说明，排查后手动重新生成或删除
已过期产物已因保留期或配额清理手动重新生成或删除记录

部分完成不代表缺失指标为零。应结合报告各节的数据状态和覆盖范围阅读。

4. 预览、下载和打印

  1. 对已完成或部分完成的任务点击 预览，在隔离窗口中查看 HTML。
  2. 点击 下载 HTML，保存到本地后用浏览器打开。
  3. 需要 PDF 时，在下载后的 HTML 中使用浏览器 打印 → 另存为 PDF。长表格的分页以浏览器打印预览为准。

HTML 为单文件，不需要联网加载字体或图表脚本。服务器保存的报告文件经过加密，管理端下载时会验证权限并解密，下载后的 HTML 可直接离线查看，请妥善保存。

报告是生成时保存的静态结果。修改证书、网站配置、报告语言或程序版本后，历史 HTML 不会自动更新。需要按当前配置重新生成同周期的已完成报告时，可先下载留存，再删除该任务并重新生成；结果取决于当时仍保留的数据。

5. 删除与自动清理

  • 点击 删除 并确认后，服务器产物被清理，任务从列表及总数中移除，不能继续下载；自动计划不会重新生成这个已删除周期。
  • 排队中和生成中的任务暂不能删除。
  • 已删除周期可以由用户手动重新生成，但此前已被清理的统计数据不会恢复。
  • 超过保留天数或总产物配额时，系统清理较早产物，保留 已过期 历史记录。保留期按任务创建时间计算，配额针对服务器上的报告产物。
  • 本地已下载的 HTML 不受服务器自动清理影响。

删除后仍看到“已过期”记录

自动清理产生的“已过期”历史会保留在列表中。如需从列表移除，可再点击删除。早期开发版手动删除留下的“已过期”记录，同样可再次删除。

报告包含哪些内容

内容阅读方式
周期概览与上期对比请求数、阻止数、非阻止数、入 / 出站流量、平均响应时间、去重 IP 与阻止 IP
趋势日报按小时，周报 / 月报按天；缺失时段不补造为零
动作分布按实际记录的动作汇总
TOP 榜单阻止来源 IP、规则命中、阻止路径、阻止地域
操作审计按分类、事件和成功 / 失败结果汇总；显示中文或英文名称
网站快照生成时的网站启用、防护与仅记录状态
证书快照证书名称 / 主题、域名、有效期与状态，便于定位对应证书
实例信息与数据说明生成时间、版本、访问日志档位及指标覆盖说明

证书名称优先显示主题，缺少主题时使用序列号，再缺少时使用证书编号；域名单列显示。证书状态包括有效、近期到期、已过期、尚未生效或未知。

数据口径

  • 报告从已有统计汇总、操作审计和当前网站 / 证书配置中采集，不通过扫描访问日志明细来重建统计。
  • 请求、流量、趋势和榜单来自统计数据；操作审计来自已保存的审计记录；网站与证书是生成时点快照，不代表该历史周期当时的配置。
  • 同一 IP 在统计周期内跨天或跨网站出现，只计一次；不能把每天的去重 IP 数直接相加。
  • 平均响应时间按请求数加权计算，不取每天平均值的简单平均。
  • 阻止数按实际“阻止”动作统计；规则 TOP 是规则命中次数，包含放行和验证，不等于阻止次数。
  • 请求 / IP 统计与流量字节的过滤口径不同，可能与访问日志条数不一致。详情参见报告内说明以及 数据留存、访问日志。
  • 审计汇总按实际保存的记录计数，受审计写入节流影响，不等于所有原始操作尝试次数。
  • 数据清理、小时统计保留期或数据源不可用都会影响报告覆盖范围。缺失与不可用不等于零，重新生成也不能补回已删除的源数据。

配置摘要通知

报告生成与通知发送分别配置。自动报告默认保存在本机，只有启用相应订阅与渠道后才会发送摘要。

  1. 在 通知渠道 配置并启用接收渠道。
  2. 在 通知订阅 找到 日报 / 周报 / 月报 行，为需要的类型添加并启用订阅。
  3. 如需自定义标题、正文、频率或过滤条件，打开该订阅的齿轮配置。模板变量以页面列出的当前消息类型变量为准。
  4. 在 通知日志 按报告消息类型查看成功、失败或被抑制记录。

周期通知发送报告编号、类型、周期、生成状态及请求 / 阻止等摘要指标，不发送完整 HTML 或下载附件。完整报告仍需由超级管理员在报告页面下载。摘要通知沿用已有频率控制、过滤与免打扰配置；本地生成成功不代表通知必然送达。

常见问题

能看到入口，但报告设置加载失败？

先核对前后端版本是否配套。前端 v1.3.335 已有入口，旧后端可能尚无报告接口；同时确认使用超级管理员登录。普通管理员和开放平台 API Key 不能管理全实例报告。

为什么开启后没有立刻生成昨天的报告？

首次启用不回补已结束周期。需要旧周期时手动生成；自动报告会等待当前周期结束并到达计划时间。还应检查总开关、对应类型开关、服务器时间与时区，并确认 SamWaf 持续运行。

为什么旧日报缺少小时趋势，或报告显示部分完成？

小时统计和其他数据有各自的保留范围，历史数据可能已经清理，也可能有数据源暂时不可用。以报告中的缺失说明为准；不要将这些值解释为零。

已生成报告，为何没收到通知？

手动生成不发送周期摘要。自动生成时需要启用对应报告类型的订阅和渠道，再到通知日志检查发送结果与抑制原因；订阅的域名、关键字、严重级别等过滤条件也可能影响摘要发送。

改了语言或证书信息，重复生成仍看到旧内容？

同周期已完成的任务会复用，历史 HTML 不会重绘。确认已留存需要的文件后，删除该任务并手动重新生成。
