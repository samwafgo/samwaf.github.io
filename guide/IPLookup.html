IP归属查询

功能简介

一个 IP 可能同时被好几个地方管着：IP黑名单、IP白名单、IP组、威胁情报IP订阅、IP失败封禁、CC封禁、防火墙IP封禁，还可能落在 CDN 回源段里。排查「这个 IP 为什么被拦了」或者「为什么没拦住」时，挨个页面翻既慢又容易漏。

IP归属查询把这件事收敛成一次查询：输入一个 IP，一次问遍上述全部来源，直接给出结论——会被放行 / 会被拦截，并列出是被哪一条规则、哪个网站、哪个渠道命中的。确认是误判还可以就地加白，确认是恶意 IP 也可以就地拉黑。

判定按网段语义进行：查 1.2.3.4 会命中名单里的 1.2.3.0/24，不是简单的文字比对。

在哪里打开

以下页面的右上角都有 IP归属查询 按钮：

页面位置
防护日志 → 风险日志顶部说明条右侧
防护日志 → 访问日志顶部说明条右侧
网站防护 → 威胁情报IP订阅顶部说明条右侧
网站防护 → CDN回源IP顶部说明条右侧
系统设置 → IP失败封禁「刷新」按钮右侧

此外，下列位置的 IP 本身就是可点击的，点一下直接打开查询并自动出结果，不用复制粘贴：

  • 风险日志列表的 IP 列
  • 访问日志列表的 来源IP 列
  • IP失败封禁列表的 IP 列
  • 威胁情报IP订阅 →「查看IP」弹窗里的每条 IP / 网段
  • CDN回源IP →「查看IP」弹窗里的每条网段

操作步骤

查询一个 IP

  1. 在任一入口打开 IP归属查询。
  2. 输入要查的 IP，点 查询（或直接回车）。
  3. 查询按 4 批并发进行，下方会依次显示进度：名单、封禁记录、威胁情报IP、CDN回源段。先查完的批次会先显示结果，不必等全部结束。
  4. 结果区顶部给出 IP、归属地和结论；下方按来源逐条列出命中详情。

也可以直接查网段

输入框接受网段（如 1.2.3.0/24）和区间（如 1.2.3.5-1.2.3.9）。这种情况会按其中一个代表 IP 查询，并在结果里注明实际查的是哪个 IP。

把误判的 IP 加入白名单

  1. 查询结果显示 会被拦截 时，命中列表下方会出现 加入白名单 按钮。
  2. 点开后选择 生效网站（默认「全局网站」，即对所有站点生效）。
  3. 加白原因 已自动填好，内容包含日期和原本命中的来源，可以修改但不能留空。
  4. 点 确认。系统会自动重新查询一次，你可以直接看到结论发生变化。

白名单只在 WAF 应用层生效

如果这个 IP 是被系统防火墙层拦住的（防火墙IP封禁，或落地层为「系统防火墙 / 两者」的威胁情报渠道），加白表单里会出现一条橙色提醒。

因为系统防火墙是在操作系统层面直接丢弃数据包的，请求根本到不了 WAF，IP白名单在这种情况下不会生效。加白之后结论会显示「WAF层已放行，系统防火墙层仍拦截」。

要彻底放行，请到 防火墙IP封禁 页面解封，或把对应威胁情报渠道的落地层改成「仅WAF应用层」。

把恶意 IP 加入黑名单

  1. 查询结果里这个 IP 不在黑名单、也不在白名单时，会出现 加入黑名单 按钮。
  2. 选择 生效网站、封禁层级（仅WAF应用层 / 系统防火墙 / 两者，默认「仅WAF应用层」）。
  3. 填写 拉黑原因（同样已自动预填）。
  4. 点 确认，系统会自动重新查询一次。

结论说明

结论含义
未命中任何名单该 IP 当前不在任何黑白名单、封禁记录或威胁情报里
会被放行命中了白名单，且没有系统防火墙层的拦截
会被拦截命中了黑名单 / 威胁情报 / 各类封禁
WAF层已放行，系统防火墙层仍拦截已加白，但系统防火墙层仍在丢包，需另行处理
已命中，但不直接影响放行/拦截例如只命中了 CDN 回源段，或命中的 IP组 未被任何黑白名单引用

字段说明

结果列表里每一条命中包含：

字段说明
来源命中来自哪里：IP白名单、IP黑名单、IP组、威胁情报IP、IP失败封禁、CC封禁、防火墙IP封禁、CDN回源IP
归属范围该条属于哪个网站 / 哪个 IP组 / 哪个订阅渠道 / 哪个 CDN 厂商。全局生效的显示「全局网站」
命中规则实际匹配上的那条规则原文（单 IP、网段、通配符或区间）。缓存类封禁没有规则原文，此处为空
效果放行 / 拦截 / 仅标记
补充说明备注、剩余封禁时间、威胁情报的落地层等

常见问题

查询覆盖哪些来源？

IP白名单、IP黑名单、IP组、威胁情报IP、IP失败封禁、CC封禁、防火墙IP封禁、CDN回源IP段，共 8 类。

为什么第一次查询稍慢，之后就很快？

威胁情报和 CDN 回源段的数据量可能达到十万条级别，首次查询需要编译一次索引（通常数百毫秒），之后会复用，直到对应渠道重新同步过为止。

结果里提示「以下来源本次查询失败，结果可能不完整」是什么意思？

某一类来源没能查成功（例如快照正在同步）。此时不能把「没查到」当成「不在名单里」，建议稍后重试。

命中里显示「站点已不存在，该条不生效」？

这条名单绑定的网站已经被删除了，它实际不会起作用，可以到对应的黑/白名单页面清理掉。

加入白名单后为什么还是访问不了？

多半是被系统防火墙层拦着的。请看上文 白名单只在 WAF 应用层生效 的说明。
