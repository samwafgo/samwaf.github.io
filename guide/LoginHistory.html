登录历史

功能简介

登录历史用于回答「我的管理端账号上次是从哪里登录的、这次和上次是不是同一个地方」。

它由两部分组成：

  • 登录提醒：每次登录成功进入系统后，页面右下角自动弹出提示，显示本次登录的 IP 与归属地，并与该账号上次登录做对比。若来源发生变化，会额外列出上次的 IP、归属地与登录时间。
  • 登录历史列表：在「账号管理 → 登录历史」中查看每个账号的历次登录记录，包含 IP、归属地、登录端、客户端信息与来源是否变化。

前置条件

  • 登录提醒对所有登录管理端的账号都会显示，无需任何配置。
  • 登录历史列表属于审计范畴，需要 超级管理员 或 审计管理员 角色才能查看。角色在 账号管理 中设置。
  • 归属地依赖内置 IP 库，若显示为「未知」请检查 IP数据库管理。

操作步骤

1. 查看登录提醒

登录成功进入系统后，右下角会自动弹出提示框，无需任何操作：

  • 来源与上次一致：绿色提示框，标题为「登录提醒」，显示本次登录 IP、归属地、登录时间，提示语为「与上次登录来源一致。」，约 6 秒后自动关闭。
  • 该账号首次登录：同样是绿色提示框，提示语为「这是该账号的首次登录记录，下次登录会与本次进行比对。」。老版本升级上来的账号，第一次登录会看到这条提示。
  • 来源发生变化：橙色提示框，标题为「登录来源变化提醒」，除本次信息外还会列出 上次登录IP、上次归属地、上次登录时间，提示语为「本次登录来源与上次不一致，若非本人操作请立即修改密码。」。

注意

来源变化的提示框不会自动关闭，需要手动点击右上角关闭按钮，避免因为离开电脑而错过告警。提示框底部提供 查看登录历史 按钮，点击可直接跳转到登录历史页面。

提示

提示框在每次登录后只弹一次，刷新页面不会重复出现。

2. 查询登录历史

进入「账号管理 → 登录历史」，页面顶部提供三个筛选条件：

  1. 登录账号：输入账号名精确匹配。
  2. 登录IP：输入 IP 精确匹配。
  3. 来源变化：下拉选择「全部 / 已变化 / 未变化」。

填好后点击 查询（输入框中按回车同样生效）。列表按登录时间倒序展示，支持分页。

「来源变化」列以标签形式展示三种状态：

标签含义
首次登录（灰色）该账号的第一条登录记录，没有可比对的上次记录。
已变化（橙色）本次登录的 IP 或归属地与上次不同。
未变化（绿色）与上次登录来源一致。

只有「已变化」的记录，上次IP 列才会有值，其余显示 -。

3. 接收登录来源变化告警

如果希望人不在电脑前也能第一时间知道，可以把来源变化推送到钉钉、飞书、企业微信、邮件等渠道：

  1. 先到 通知渠道 配置好接收渠道。
  2. 到 通知订阅，在消息类型 管理端登录来源变化 这一行，勾选要接收的渠道。
  3. 之后每次出现来源变化登录，都会推送一条「管理端登录来源变化告警」，正文包含本次与上次的 IP、归属地和时间。

提示

「管理端登录来源变化」与「用户登录」是两个独立的消息类型：前者只在来源变化时触发，后者每次登录都会触发。如果只想收异常告警、不想被日常登录打扰，只订阅前者即可。

常见问题

为什么每次登录都提示「来源变化」？

先确认是不是 IP 本身在变。常见原因：

  • 使用动态公网 IP（家庭宽带拨号），每次拨号都会换 IP。
  • 通过不同网络访问，例如时而用公司内网、时而用手机热点。
  • 同一 IP 但 IP 库更新导致归属地文本发生变化，也会被判定为变化。

可以在登录历史列表中对比前后两条记录的 登录IP 与 归属地 列确认具体是哪一项变了。

登录历史页面打不开或没有数据？

该页面属于审计范畴，只有 超级管理员 与 审计管理员 能访问。请在 账号管理 中确认当前账号的角色。

归属地显示「未知」？

说明 IP 库没有命中该地址。内网 IP 本身就没有公网归属地；若公网 IP 也显示未知，请到 IP数据库管理 检查 IP 库是否正常加载。

登录历史会一直累积下去吗？

不会。每个账号只保留最近 200 条登录记录，超出后自动清理最早的记录。

清理过日志后，是不是所有账号都会变成「首次登录」？

不会。用于比对的「上次登录」信息单独保存在账号上，不随日志清理丢失。清理只会影响登录历史列表里能查到的记录条数。

强制修改密码后还会弹提示吗？

会。首次登录或密码到期被要求改密时，改密完成进入系统后仍然会弹出登录提醒。
