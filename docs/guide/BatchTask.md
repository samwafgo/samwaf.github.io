# 批量任务

## 功能简介

批量任务用于自动执行一些批量化操作，每日凌晨 5 点依次执行，也支持手工触发。可将本地文件或远端 URL 中的数据批量导入系统，目前支持批量添加白名单 IP、黑名单 IP、导入到 [IP组](./IPGroup.md) 和添加敏感词。

::: tip
如果要维护的这批 IP 需要在**多个站点**上同时生效，推荐用「导入到IP组」而不是直接导进某个站点的黑/白名单：一份来源导进一个组，所有引用该组的站点同时生效，来源更新时也只需维护这一个任务。详见 [导入到IP组](#导入到ip组)。
:::

## 操作步骤

### 1. 新建批量任务

点击左上角"新建"按钮，打开新建对话框。

![批量任务添加界面](/images/batchtask_2.png)

### 2. 填写任务信息

依次填写任务名称、网站、任务类型、额外配置、来源类型、来源值、执行方式、触发类型与备注。

- 选择不同的"任务类型"时，"额外配置"会自动填入对应的默认 JSON 模板（敏感词类型才需要额外配置，IP 类型为 `{}` 即可）。
- **任务类型选"导入到IP组"时表单会变化**：因为 IP 组不属于任何网站，"网站"与"额外配置"会隐藏，改为出现"目标IP组"下拉，选择要导入的组即可。
- 来源类型为"本地路径"时，来源值填写服务器上的本地文件路径；为"远端 URL"时填写可访问的 http(s) 地址。

填写完成后点击"确认"保存。

### 3. 手工触发

在列表对应行点击"手工触发"，确认后即可立即执行该批量任务，无需等待每日定时执行。

### 4. 编辑与删除

- 点击"编辑"可修改已创建的批量任务。
- 点击"删除"并确认后即可移除该任务。

## 导入到IP组

[IP组](./IPGroup.md) 是可跨站点复用的 IP 集合。选择该任务类型后，来源里的 IP 会被导入到指定的 IP 组，**所有引用该组的站点（含全局网站）与防护规则会同时生效**，不需要给每个站点各建一个任务。

典型用法：把一份威胁情报清单或公司出口 IP 清单做成定时任务，每天自动同步到一个 IP 组，再让各站点的黑/白名单引用这个组。

与其它任务类型的差别：

- **不绑定网站**：表单里没有"网站"字段，改为选择"目标IP组"。目标组必须是已经建好的组（下拉为空时请先到 **网站防护 → IP组** 新建）。
- **执行方式"覆盖"是全量同步**：导入完成后，会**删除组内本次来源中已不存在的 IP**，使组内容与来源保持一致——来源里被移除的 IP 会自动从组里消失。其它任务类型的"覆盖"只更新不删除。
- 来源里 `*.*.*.*` 这类会匹配所有 IP 的写法会被跳过，与手工录入 IP 组的限制一致（详见 [IP组 - 支持的 IP 写法](./IPGroup.md#_2-3-支持的-ip-写法)）。

::: warning
"覆盖"会删数据，因此设置了三重保护，任意一条不满足就**完全不执行删除、组内容原样保留**：

1. 执行方式必须是"覆盖"（"添加"永远只增不减）；
2. 来源必须被完整读取（读取中途出错时不删）；
3. 来源里至少要有一条有效 IP（来源为空文件、远端返回 404 页面时不删）。

远端 URL 不可访问或返回非 200 时任务会直接结束，同样不会删除任何数据。
:::

## 字段说明

| 字段 | 说明 |
| --- | --- |
| 任务名称 | 自定义的任务标识名称（必填） |
| 网站 | 任务作用的网站，从下拉列表中选择（必填；任务类型为"导入到IP组"时该字段隐藏且不需要填写） |
| 任务类型 | 添加白名单 IP / 添加黑名单 IP / 导入到IP组 / 添加敏感词（必填） |
| 目标IP组 | 仅"导入到IP组"类型出现，选择要导入的 IP 组（必填）。下拉显示「组名称 (条目数)」，右侧"去管理IP组"链接可跳转到 IP组 页面 |
| 额外配置 | JSON 格式的额外配置。敏感词类型支持 `check_direction`（检测方向：in 入站、out 出站、all 双向）与 `action`（检测后动作：deny 拒绝、replace 替换）；IP 类型无需配置（`{}`）；"导入到IP组"类型由"目标IP组"下拉维护，该字段不展示 |
| 来源类型 | 本地路径 / 远端 URL（必填） |
| 来源值 | 本地路径填写本地文件路径，远端 URL 填写 http(s) 地址（必填） |
| 来源内容格式 | 每行一条。IP 类任务支持单 IP、CIDR 网段、通配符（如 `10.10.*.*`）与区间（如 `1.2.3.4-1.2.3.99`），与手工录入黑白名单的写法一致；无法识别的行会被跳过 |
| 执行方式 | 添加（已存在的跳过，只补充新数据）/ 覆盖（必填）。**"覆盖"的含义随任务类型不同**：IP 黑白名单与敏感词类型为已存在的更新、不存在的新增，不会删除任何已有数据；"导入到IP组"类型为全量同步，会删除组内来源中已不存在的条目 |
| 触发类型 | 定时任务（每日定时执行）/ 手动任务（仅手工触发）（必填） |
| 备注 | 可选的补充说明信息 |

## 常见问题

- **额外配置填写后无法保存？** 额外配置必须是有效的 JSON 格式，请检查括号、引号是否完整。
- **定时任务什么时候执行？** 触发类型为"定时任务"的批量任务每日凌晨 5 点依次执行；如需立即执行可使用"手工触发"。
- **"目标IP组"下拉是空的？** 说明还没有创建过 IP 组，请先到 **网站防护 → IP组** 新建一个组。
- **选了"覆盖"，但组里多余的 IP 没被删掉？** 说明命中了上面的保护条件之一：来源读取中途出错，或来源里没有任何有效 IP。此时组内容会保持原样，请检查来源文件/地址是否正常。
- **导入到 IP 组后，站点上要重启或重新保存吗？** 不需要。组内容变更对所有引用该组的站点即时生效。
