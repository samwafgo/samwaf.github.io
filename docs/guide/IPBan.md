# IP封禁

## 功能简介

「IP封禁」把原来分散的**规则封禁**与**IP失败封禁**合并成一个统一入口，按来源管理当前所有针对客户端 IP 的封禁：

- **规则封禁**：防护规则命中 `RF.Ban(分钟)` 后，在当前站点临时封禁该 IP。
- **失败计数**：源站返回失败状态码的次数统计，供规则 `MF.GetIPFailureCount(分钟)` 判断；命中阈值的记录在此列出。
- **CC封禁**：CC 防御产生的封禁，沿用原 CC 封禁列表与操作。

三个来源各自沿用原有判定与存储机制，互不影响；列表只提供统一入口，不改变任何来源的封禁语义。

## 封禁列表

1. 进入 **网站防护 → IP封禁**，默认显示「封禁列表」。
2. 「来源」切换 **规则封禁 / 失败计数 / CC封禁**，各自展示对应列表；切换时才加载对应数据。
3. 每条封禁记录支持**详情**（查看该 IP 的访问日志）与**解除**：
   - 规则封禁：解除当前行的站点封禁；
   - 失败计数：清除该 IP 的失败记录，**同时清除该 IP 的 CC 封禁，但不解除规则封禁**（确认弹窗会再次说明）；
   - CC封禁：沿用原 CC 封禁的解除操作。

页面右上角的 **IP策略命中查询** 一次查遍所有来源，可直接在查询结果里「解除规则封禁」（解除该 IP 所有站点的规则封禁）。

## 配置

「配置」分三块，每块独立保存：

- **规则封禁**：封禁执行动作——`返回拦截页`（默认）或 `直接断开`；仅作用于规则封禁后的后续请求，CC 封禁的处理方式不变。块内附规则示例，可一键复制后到「规则管理」粘贴。
- **失败计数**：启用开关、失败状态码（支持多个与正则）、数据保留时间（分钟）。保留时间只是失败记录的统计窗口上限，**不等于** `RF.Ban(分钟)` 的封禁时长。
- **CC封禁**：CC 的触发条件、阈值、作用范围和封禁时长继续在 **CC防御** 中设置，此处提供跳转。

## 规则示例

封禁当前请求并把 IP 在站点封禁 10 分钟：

```
rule Rexample "命中即封禁10分钟" salience 10 {
    when
        MF.URL.Contains("/wp-admin") == true
    then
        RF.Ban(10);
}
```

配合失败计数，5 分钟内失败超过 10 次封禁 10 分钟：

```
rule Rexample2 "5分钟内失败超过10次，封禁10分钟" salience 10 {
    when
        MF.GetIPFailureCount(5) > 10
    then
        RF.Ban(10);
}
```

要点：

- `RF.Ban(分钟)` 写在**已启用规则**的动作（then）里即生效，没有独立开关；命中即拦截当前请求并写入封禁。
- 已有封禁**不续期**（剩余时间只减不增），要延长只能解封后重新命中。
- 封禁只作用于**触发规则的站点**，其它站点不受影响。
- 站点「仅记录模式」下只留痕、不写入封禁。
- 白名单 IP 不受规则封禁影响。
