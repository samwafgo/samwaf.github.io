# 访问账号

## 1 功能简介

这里维护的是 **[统一访问认证](./AccessConfig.md) 的访客账号**——也就是"谁可以通过这道门"。

页面顶部提示：**这里的账号是给访客登录用的，与管理端登录账号完全分开，也与站点的【网站密码访问】互不影响。密码采用 bcrypt 存储，无法读回。**

::: tip
开启统一访问认证之前，**先在这里建好至少一个账号**，否则总开关一开谁都进不去。
:::

<!-- 图：访问账号列表页 -->

## 2 操作步骤

### 2.1 新增账号

1. 进入 **统一访问认证 → 访问账号**，点击左上角 **新增账号**。
2. 填写 **登录名** 与 **密码**（均为必填）。
3. 按需填写 **显示名**、**状态**、**二次验证**、**可访问站点**、**账号有效期**、**备注**。
4. 点击 **确认** 保存。

::: warning
**登录名创建后不可修改**（会话与审计日志以它关联）。要改只能删号重建。
:::

密码复杂度沿用管理端的口令策略——访问账号是公网可达的登录入口，没有理由比管理端宽松。

<!-- 图：新增访问账号弹窗 -->

### 2.2 可访问站点

默认**不选**，表示允许访问全部站点（推荐，多数自用场景都够用）。

选定站点后，该账号只能访问所选站点。下拉里直接选站点名即可，不需要填内部编码。列表中会显示 **全部站点** 或 **限 N 个站点**，鼠标悬停可看到具体站点名。

::: warning
站点被删除时会自动从这里摘掉；**若摘完一个不剩，账号会被自动禁用**。
这是刻意设计：空列表的语义是「全部站点」，直接留空会把一个原本受限的账号提权成全站可访问，方向完全反了。此时请重新给它勾选站点后再启用。
:::

### 2.3 账号有效期

留空表示**永不过期**。到期后无法登录，**已有会话也会失效**。

### 2.4 二次验证（动态口令）

在列表行的 **操作** 列点击 **二次验证**：

- **未绑定** 时：用验证器 App 扫描弹窗里的二维码（或手动输入 **密钥**），然后输入一次 **动态验证码** 完成绑定。只有输入正确才会真正绑定，不会出现系统记着已绑定、手机上却没有的情况。
- **已绑定** 时：可点击 **解除绑定**。解绑后登录将不再需要动态验证码。

<!-- 图：二次验证绑定弹窗 -->

账号编辑里的 **二次验证** 字段控制是否强制：

| 取值 | 说明 |
| --- | --- |
| 继承全局 | 跟随站点与全局设置 |
| 强制 | 该账号登录必须输入动态码 |
| 豁免 | 该账号不要求动态码 |

::: tip
账号级设置优先于站点与全局设置。**未绑定动态口令的账号不会被强制**——否则会被锁死在登录页。
:::

### 2.5 重置密码

点击 **重置密码**，填写新密码即可。

::: warning
重置密码会**同时踢掉该账号的全部在线会话**，这是密码疑似泄露时的止血动作。
:::

### 2.6 踢下线与删除

- **踢下线**：将该账号的全部在线会话强制下线，通常立即生效。
- **删除**：删除账号会同时踢掉它的全部在线会话，且不可恢复。

把状态改为 **禁用** 同样会立即踢掉该账号已有的在线会话。

### 2.7 搜索

页面右上角支持按 **登录名** 模糊筛选，输入后点击 **查询**。

## 3 字段说明

| 字段 | 说明 |
| --- | --- |
| 登录名 | 访客登录用的账号名，必填；**创建后不可修改** |
| 密码 | 新建时必填，bcrypt 存储、无法读回；改密走「重置密码」 |
| 显示名 | 便于识别的名称，可选 |
| 状态 | 启用 / 禁用；改为禁用会立即踢掉该账号的在线会话 |
| 二次验证 | 继承全局 / 强制 / 豁免；账号级优先级最高 |
| 可访问站点 | 不选=全部站点；选定后仅能访问所选站点 |
| 账号有效期 | 留空=永不过期；到期后无法登录且已有会话失效 |
| 备注 | 自定义说明信息，可选 |
| 最后登录时间 | 最近一次成功登录的时间（列表展示） |
| 最后登录IP | 最近一次成功登录的来源 IP（列表展示） |

## 4 常见问题

- **账号怎么突然变成禁用了？** 它唯一授权的那个站点被删除了。给它重新勾选可访问站点后再启用即可，详见 [2.2](#_2-2-可访问站点)。

- **给账号只授权了某个站点，它能登进认证中心吗？** 能。登录发生在认证中心上，那一步不判站点授权；真正的逐站点判定发生在跳转回业务站点的过程中。所以**不需要**把认证中心也加进每个账号的可访问站点列表。

- **绑了动态口令，但登录不要求输入？** 检查三层设置：账号级「二次验证」是否为豁免、站点级是否为豁免、[认证配置](./AccessConfig.md) 里的全局二次验证是否关闭。优先级是账号 > 站点 > 全局。

- **忘记访问账号密码怎么办？** 管理员在本页点 **重置密码** 直接设一个新的即可（会同时踢掉该账号的在线会话）。

- **这些账号能登管理端吗？** 不能。访问账号只用于通过统一访问认证访问被代理的业务站点，与管理端 `26666` 的登录账号完全隔离。
