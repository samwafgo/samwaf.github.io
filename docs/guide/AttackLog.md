# 风险日志（防护日志）

## 功能简介

风险日志（也称防护日志 / 攻击日志）以 **来源 IP** 为维度，汇总统计触发了 WAF 防护规则的访问情况，帮助你快速发现攻击者、查看其触发的规则集合，并下钻到具体的访问明细。

页面顶部按「触发规则」分组展示标签页，可在不同规则之间快速切换查看；同时支持按规则、来源 IP 进行查询过滤。

![风险日志](/images/attacklog.png)

::: tip 想知道某个 IP 现在被什么拦着？
列表里的 IP 是可以点击的，点一下会打开 **IP归属查询**，一次查遍黑白名单、IP组、威胁情报、各类封禁与 CDN 回源段，并可就地加白或拉黑。详见 [IP归属查询](./IPLookup.md)。
:::

## 操作步骤

### 1. 查询与筛选

1. 通过顶部 **触发规则** 标签页或下拉框选择要查看的规则（选「所有规则」查看全部）。
2. 在 **IP** 输入框填入来源 IP 进行精确查询。
3. 点击 **查询** 执行筛选，点击 **重置** 清空条件。
4. 列表默认按首次/最新访问时间排序，可点击列头进行排序。

### 2. 查看某 IP 的访问明细

- 在列表某行点击 **详情**，会弹出该 IP 的「访问 IP 明细」，列出该来源 IP 的具体访问/防护日志记录，便于逐条分析请求内容。
- 明细里有 **全部行为 / 安全事件** 两个视图：默认落在「安全事件」（该 IP 命中规则的那些请求，带完整报文），
  切到「全部行为」可以看这个 IP 的**所有**请求——包括没命中任何规则的那些，用来判断它到底在干什么。

### 3. 将 IP 加入黑名单

- 在 **IP** 列每个 IP 旁有 **加入黑名单** 按钮，点击并确认后即可把该 IP 加入拦截名单。

### 4. 删除规则标签

- 选中某条规则标签后点击 **删除**，可删除该规则标签；删除时会询问删除方式：
  - **仅删除标签**：只删除标签统计数据，不影响原始日志。
  - **同时删除日志**：删除标签及其所有相关的攻击日志（数据量大时较慢且不可恢复，请谨慎）。
- 点击 **批量删除** 可一次选择多个规则标签删除，同样支持上述两种删除方式。

### 5. 加入观察名单（全量留痕）

普通请求默认只留一行窄行、不留报文，所以事后想复盘「这个 IP 在被拦之前还摸过什么」往往没有报文可看。
观察名单就是为此准备的：

1. 在列表某行点击 **加入观察**。
2. 在弹窗里确认 IP，填 **观察天数**（1~30，默认 7 天）与 **原因**（选填，如「触发 SQL 注入规则」）。
3. 确认后，观察期内该 IP 的**所有**请求都会连同完整报文留痕，到期自动失效。

### 6. 管理观察名单

- 点击工具栏的 **观察名单** 打开管理弹窗，可以看到名单里的 IP、到期时间与原因。
- 点 **移出** 可提前结束对某个 IP 的观察。

::: warning 观察是有代价的
观察期内该 IP 的每个请求都会存一份完整报文，被观察的 IP 如果流量很大会明显占空间。
建议只对确有嫌疑的 IP 短期观察，别把它当成长期开关。
:::

## 字段说明

| 字段 | 说明 |
|------|------|
| IP | 触发规则的来源 IP 地址；其旁有「加入黑名单」按钮。 |
| 阻止数量 | 该 IP 被 WAF 拦截（阻止）的请求次数。 |
| 放行数量 | 该 IP 被放行的请求次数，取自统计数据（不再为每个 IP 生成「正常」标签，所以标签列表更干净）。 |
| 首次访问时间 | 该 IP 第一次出现的时间。 |
| 最新访问时间 | 该 IP 最近一次出现的时间。 |
| 触发规则集合 | 该 IP 命中过的所有规则标签集合。 |
| 操作 | **详情**：下钻查看该 IP 的访问明细；**加入观察**：把该 IP 加入观察名单，期间全量留痕。 |

> 顶部「触发规则」标签来自系统记录的规则命中标签集合；AI 智能检测命中也会以 `AI检测:<类别>` 形式出现在规则标签中。

## 常见问题

- **为什么这里按 IP 聚合，而不是逐条请求？** 风险日志侧重「谁在攻击、触发了哪些规则」，按 IP 聚合更利于快速研判；要看逐条请求内容，请点「详情」进入访问明细。
- **删除标签会删掉日志吗？** 取决于你选择的删除方式。「仅删除标签」不动原始日志，「同时删除日志」才会一并删除相关攻击日志且不可恢复。
- **为什么标签里看不到「正常」了？** 系统不再为每个 IP 记「正常」标签（那会让标签表随访客数无限膨胀），放行次数改由统计数据给出，首页放行榜不受影响。
- **什么时候该用观察名单？** 当你怀疑某个 IP 但现有日志不足以判断时。观察期内它的全部请求（含普通请求）都会带报文留痕，看完记得移出。
- **观察名单里的数据在哪看？** 还是在「详情」的 **全部行为** 视图，报文在各条记录的详情里。
