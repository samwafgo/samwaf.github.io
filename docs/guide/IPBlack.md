## 2 功能简介

IP 黑名单用于设置“拦截名单”：被列入黑名单的 IP 或网段访问受保护网站时，SamWaf 会直接阻止其访问。常用于封禁恶意来源、攻击 IP、异常爬虫网段等。

页面顶部提示：**SamWaf 防护墙会阻止在黑名单内的 IP / 网段的访问**。

## 3 操作步骤

### 3.1 新增黑名单 IP

1. 点击左上角的 **新建黑名单IP** 按钮，弹出新增窗口。
2. 选择 **网站**（必填），即该黑名单生效的受保护站点。
3. 选择 **条目类型**：
   - **单条IP/网段**（默认）：直接填写 **Ip**，写法见 [3.2 支持的 IP 写法](#_3-2-支持的-ip-写法)。
   - **引用IP组**：从 **IP组** 下拉中选择一个已建好的 [IP组](./IPGroup.md)，该组内的全部 IP 一次性生效。下拉项显示为「组名称 (条目数)」，旁边的 **管理IP组** 链接可直接跳转到 IP 组页面。
4. 可在 **备注** 中填写说明信息（可选）。
5. 点击 **确认** 保存。

列表中新增了 **类型** 列区分两种条目；引用 IP 组的行，**Ip** 列显示的是「组名称 (条目数)」而非具体 IP。

<!-- 图：新建黑名单IP弹窗 -->

::: tip
同一批 IP 需要在多个站点上封禁时，建议先建一个 [IP组](./IPGroup.md)，各站点黑名单统一引用它。之后改组内容即可让所有引用站点同时生效，不必逐站点修改。
:::

### 3.2 支持的 IP 写法

| 写法 | 示例 | 说明 |
| --- | --- | --- |
| 单个 IP | `1.2.3.4`、`2001:db8::1` | IPv4 / IPv6 均可 |
| CIDR 网段 | `10.0.0.0/8`、`2001:db8::/32` | |
| IPv4 通配符 | `10.10.*.*`、`10.*.1.*` | 按八位组通配，`*` 可出现在任意位置 |
| IPv6 通配符 | `2001:db8:*:*:*:*:*:*` | 按段通配，**必须写满 8 段，且不能与 `::` 缩写混用** |
| 区间 | `1.2.3.4-1.2.3.99` | 闭区间（含起止），起止两端必须同为 IPv4 或同为 IPv6 |

输入框下方会给出同样的提示：**支持单IP、CIDR网段、通配符(IPv4按八位组如10.10.\*.\*；IPv6须写满8段且不能用::)、区间(起-止)**。

::: warning
`*.*.*.*` 与 `0.0.0.0-255.255.255.255` 这类会匹配**所有 IP** 的写法会被拒绝保存（填进黑名单等于封禁所有访客）。如确实需要，请显式填写 `0.0.0.0/0`。
:::

### 3.3 封禁层级与写法的限制

**封禁层级** 可选 **WAF应用层** / **系统防火墙** / **两者**。当条目类型为 **引用IP组**，或 Ip 中使用了**通配符 / 区间**时，**系统防火墙** 与 **两者** 两个选项会自动置灰，只能选择 **WAF应用层**，页面提示：

> 引用IP组或使用通配符/区间时只能走WAF应用层，系统防火墙不支持这些写法

原因是系统防火墙（iptables / netsh）只认单个 IP 与 CIDR 网段，无法表达通配符、区间与 IP 组引用。

### 3.4 编辑 / 删除

- 在列表每行的 **操作** 列，点击 **编辑** 可修改该条黑名单的网站、IP 与备注。
- 点击 **删除** 可删除单条黑名单（会弹出确认提示）。

### 3.5 批量删除与清空

- 勾选列表前的多选框后，点击 **批量删除** 可一次性删除所选记录（无选中时按钮不可用）。
- 点击 **清空所有** 可清空当前条件下的全部黑名单数据（会弹出二次确认）。

### 3.6 导出数据

点击 **导出数据** 按钮可将黑名单导出为 Excel 文件（`ipblock.xlsx`），便于备份或迁移。

### 3.7 搜索

页面右上角支持按 **网站** 和 **Ip** 进行筛选，输入后点击 **查询**。

## 4 字段说明

| 字段 | 说明 |
| --- | --- |
| 网站 | 黑名单生效的受保护站点，新增/编辑时必填 |
| 条目类型 | **单条IP/网段**（默认）或 **引用IP组**；决定下方填 Ip 还是选 IP 组 |
| Ip | 拦截的 IP，支持单 IP、CIDR 网段、通配符、区间（见 [3.2](#_3-2-支持的-ip-写法)），条目类型为「单条IP/网段」时必填 |
| IP组 | 引用的 [IP组](./IPGroup.md)，条目类型为「引用IP组」时必填；组内容变更后本条黑名单立即跟随生效 |
| 封禁层级 | **WAF应用层** / **系统防火墙** / **两者**；引用 IP 组或使用通配符、区间时只能选 WAF应用层 |
| 备注 | 自定义说明信息，可选 |
| 创建时间 | 记录的创建时间（列表展示，自动生成） |

::: warning
请谨慎使用 `0.0.0.0/0` 等大范围网段，避免误封正常访客。如同时配置了 IP 白名单，白名单优先放行。
:::
## 5 订阅来源

切换到顶部 **订阅来源** 页签，可只读查看落地到 WAF 应用层的 [威胁情报IP订阅](./ThreatIP.md) 各渠道汇总：名称、渠道短码、落地层、启用状态、**已生效落地数**、上次状态、上次同步时间。

出于性能考虑，订阅 IP 不会逐条写入本页的黑名单列表，而是按渠道汇总展示。点击某渠道的 **查看IP** 可分页只读浏览该渠道的具体 IP/网段，并支持按 IP/网段片段过滤。
