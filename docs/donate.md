# 支持一下 ❤️

SamWaf 是一款完全开源、免费使用的网站应用防火墙，所有代码基于 Apache 2.0 协议开放，**不捐赠也不影响任何功能的使用**。

如果 SamWaf 帮到了你，欢迎请作者喝杯咖啡 ☕。你的支持将用于：

- 服务器、域名、文档站与升级源等基础设施开销
- 测试设备与兼容性验证成本
- 持续的功能迭代与维护投入
